# Outer Solar System Reservoirs

The distant Solar System contains dynamical populations shaped by Neptune, planetary migration, and early scattering.

## Key Points

* The Kuiper Belt and scattered disk are directly observed populations.
* The Oort Cloud is inferred mainly from long-period comet orbits.
* Trans-Neptunian objects connect these reservoirs with dwarf planets and comet sources.
